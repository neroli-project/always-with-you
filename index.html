Cloudflare Workers と繋ぐとできること

  • アプリを閉じていても着信・通知： Cron Triggersで朝・昼・夜に自動メッセージ＆Web Push通知を送信
  • 記憶の永続化（KV / D1）： 過去の会話や記念日をWorkers側に保存してスマホ・PCで同期
  • APIキーの隠蔽： SecretsにGemini APIキーを保存して安全に利用

※Worker側の GEMINI_API_KEY と KV (BOYFRIEND_KV) を設定すると、APIキー未入力でも会話＆Cron自動連絡の同期ができます。

デプロイ手順メモ

  1. 横のタブ（またはチャット）にある worker.js をCloudflare Workersにデプロイ
  2. Workersの Variables and Secrets に GEMINI_API_KEY を追加
  3. (任意) KVを作成してバインディング名 BOYFRIEND_KV で紐付け
  4. 上のURL欄に発行されたURLを貼って「接続テスト」→「保存」！
